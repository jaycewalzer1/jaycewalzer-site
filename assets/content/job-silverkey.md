I founded SilverKey, a transaction OS for home sales, and led a nine-person team: hiring, sprints and the architecture. We shipped a React web app and a React Native app that integrated eXp Realty, DocuSign, ATTOM and Plaid.

Two pieces I built myself. A property ranker that blends semantic embeddings with an LLM's compatibility score, where each user's blending weights are learned from their own clicks with a regularized logistic regression. And an LLM contract-extraction pipeline that feeds a per-state compliance engine, so a flood-zone rule in one state is checked automatically against what the contract says. More in the [SilverKey project](#silverkey).

stack: React, React Native, Flask, OpenAPI, embeddings, LLMs
